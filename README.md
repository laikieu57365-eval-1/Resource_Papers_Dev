# ACL 2024 Best Resource Papers

This repository collects information about the Best Resource Papers from ACL 2024, including their official GitHub repository links.

## Best Resource Paper Awards

- Latxa: An Open Language Model and Evaluation Suite for Basque -- https://github.com/hitz-zentroa/latxa
- Dolma: an Open Corpus of Three Trillion Tokens for Language Model Pretraining Research -- https://github.com/allenai/dolma
- AppWorld: A Controllable World of Apps and People for Benchmarking Interactive Coding Agents -- https://github.com/StonyBrookNLP/appworld

## About

This collection is based on the [ACL 2024 Best Papers page](https://2024.aclweb.org/program/best_papers/#best-resource-paper-awards).

The ACL 2024 Best Resource Paper Awards recognize papers that make significant contributions to resources such as datasets, corpora, tools, and models that benefit the NLP research community.
